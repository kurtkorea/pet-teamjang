> 근거: 「20261016 횡성 펫 리조트 보고자료(파우코리아)」(외부 자료 · 저장소 미포함) · `PET-Aeye_CCTV_서버_비용산정_초안.md`(단가 기준) · `PET-Aeye_홈서비스_기획_초안.md`(NPU 카메라)

> 보고자료는 텍스트 부분만 반영했습니다. 배치도 · 평면도 확인 후 수량을 갱신합니다.

> **v0.3**: 횡성 관제실을 **영종 · 횡성 통합 관제실**로 확대(관제 1,200 → 2,300) · 직원용 Wi-Fi AP 추가(450, 영종과 기준 통일). 세 안 모두 같은 기준으로 다시 계산했습니다.  
> **v0.4**: NPU 카메라를 **Wi-Fi + PoE 통합형 단일 제품**(대당 약 10.3만원)으로 변경 · 영종 합계를 영종 문서 v0.4(0.80억)로 갱신 · UPS를 비상발전기 연계 소용량으로 조정 · **온프레미스 IT 거점 약 80평**(서버실 · 통합 관제실 · 사무실 8인 · CTO실) 반영(§5.5) — 서버실 · 관제실 UPS는 서버실 공사로 옮기고 카메라 쪽은 층별 통신실 UPS(250)만 남김 · 업무용 서버 · IT 장비(§5.5.4) · **사내 시스템 · 리조트 예약관리**(§5.6) 반영 · **역할 분담**: 파우코리아 = 시행사 · 헤드쿼터, 반얀트리 = 객실 · 리조트 운영(§2.2 · §5.6) · **NPU 모델 · 펌웨어 OTA**(§4.2).  
> **v0.5**: 지상 플레이그라운드 · 어질리티 등 넓은 실외는 카메라 비전 + **Minew MWB01 · MOKO MKGW1-BW** BLE 개체 추적(`PET-Aeye_넓은공간_BLE개체추적_초안.md` **v0.4** — BOM·KPI·혼잡슬롯·도킹·리캡).

- 신축이므로 배선은 통신공사에 포함하고 **추가분(대당 약 4만원)만** 반영했습니다. 기존 건물 리트로핏(대당 15만원) 대비 약 3,700만원 절감입니다.
- NPU 카메라는 영종 펫호텔 · 홈서비스와 **같은 제품(AX630C · 1GB · Wi-Fi + PoE 통합형)** 이고, 횡성은 PoE로 연결합니다. 리조트 물량은 **2차 양산(약 330대)** 으로 잡습니다(§8).

- 처음 기준(영종 서버형 1.66억 + 횡성 혼합형 1.41억 = 3.07억, 통합 관제 미반영) 대비 **약 8,800만원** 적습니다.
- 영종 기존 배선이 없어 천장 콘센트를 새로 달면 영종 0.89억 · 합계 약 2.28억입니다.
- 횡성 **온프레미스 IT 거점(서버실 · 관제실 · 사무실 · CTO실 약 80평)** 은 위 금액과 별도이며 **파우코리아(시행 · HQ)** 부담입니다(§2.2 · §5.5.5). 건축 · 설비 · 인테리어 약 2.3~4.0억 + 업무용 서버 · IT 장비 1단계 약 1.35억(**GPU·사내 LLM 개관 포함**) + HQ · PET-Aeye 연동 시스템 약 0.6억(§5.6) = **개관 시 약 4.3~6.0억** (개관 후 2단계 장비 약 0.27억 추가). HQ 시스템 구독료는 월 약 120~200만원 · GPU 전력·공조 포함 시 서버실 쪽 월 약 230~260만원입니다.
- **반얀트리(객실 · 리조트 운영)** 쪽 PMS · POS · 프런트 단말 등은 운영계약 · 브랜드 표준에 따르며, 본 문서 파우코리아 합계에 넣지 않았습니다(§5.6.5 참고 금액 약 1.0억 · 월 약 400~650만).
- microSD: 영종은 연속 녹화 1단 저장용으로 고내구성 128GB(대당 2.5만)를 넣었습니다. 횡성은 유선 PoE로 안정적이고 객실은 이벤트 녹화만 하므로 **microSD를 넣지 않았습니다**. 장애 대비 버퍼가 필요하면 32GB(대당 약 1만 · 310대 약 340만원, 예비비 포함)를 추가합니다.
- 1차 양산(2027 · 영종 · 홈서비스)과 2차 양산(횡성 준공 전)이 **같은 통합형 제품**이라, 2차는 같은 사양으로 재주문만 하면 됩니다.
- 횡성 큰 객실 89실에 1대씩 추가하면 NPU 카메라 549대 · 합계 585대입니다.

## 4. 설치 형태

| 구역 | 형태 | 이유 |
|------|------|------|
| 객실 | **NPU 카메라** | 객실 영상을 서버로 상시 보내지 않아 사생활 · 대역폭 · GPU 비용이 줄어듭니다. 카메라가 이벤트(이상행동 · 짖음 · 이탈)만 올립니다. |
| 실내 공용 | **NPU 카메라** | 같은 기판 · 같은 모델. 보안 연속 녹화는 RTSP로 녹화 스토리지에 따로 보냅니다. |
| 실외 | 시중 실외 CCTV + **엣지 박스 2대** (AX650N급 · 16~32채널, 1대는 예비) | 횡성 겨울(영하 20℃ 안팎) · 방수 · 히터 요건은 실내 기판과 다른 제품이라, 30대 물량으로 별도 금형을 만들지 않습니다. |
| 넓은 실외 플레이존 | 위 CCTV + **BLE 태그 추적** | 입장 시 **Minew MWB01**을 **목줄 관통·몸쪽 밀착형** 실리콘 케이스에 넣어 착용(매달림형 금지 · 상대견 물어뜯김), **MOKO MKGW1-BW** 격자로 ID 유지. 상세: `PET-Aeye_넓은공간_BLE개체추적_초안.md` |

**여러 마리 분석:** YOLO 탐지 · 포즈 모델은 한 번의 추론으로 화면 안 모든 개체를 처리하므로 마리 수가 늘어도 부하가 거의 같습니다. 개체 추적(ByteTrack 등)은 카메라 CPU에서 수십 마리까지 처리합니다. 넓은 공간은 입력 960 또는 4K 영상 분할 분석으로 먼 개체를 잡고, 카메라 간 이동 · 혼잡도는 앱 · DB 서버가 결과값만 모아 집계합니다(GPU 불필요).  
**넓은 실외 ID 유지:** 비전만으로는 원거리·혼잡에서 동일 개체 ID가 끊기기 쉬워, 플레이그라운드·어질리티·광장은 **BLE 태그(MWB01) + 게이트웨이(MKGW1-BW)** 로 입장~퇴장 동안 ID·구역 체류를 보완합니다. 카메라는 행동·이상행동, BLE는 개체·구역을 맡기고 같은 stay_id로 조인합니다.

#### 5.5.6 설계 조건

- **위치:** 지하(침수) · 최상층(지붕 누수) · 사우나 · 주방 · 수영장 아래를 피해 지상 저층(예: 2층 근생)에 둡니다.

- **전원:** 한전 인입 2회선 가능 여부 · 비상발전기 회로 연결 · 서버 구역 전용 분전반.
- **공조:** 일반 냉난방과 분리된 24시간 정밀 공조 · 실외기 자리.
- **회선:** 서로 다른 통신사 2회선을 **다른 경로**로 인입 (한쪽 공사 · 단선 대비).
- **소음 · 보안:** 서버 구역과 사무실 사이 차음벽 · 서버 구역 출입 기록 · 관제실 별도 출입.

#### 5.6.4 PMS 선택

- 객실 PMS는 **반얀트리 브랜드 표준**을 따르는 것이 기본입니다. 파우코리아가 별도 SaaS PMS를 새로 고르지 않습니다.
- 파우코리아가 볼 것은 (1) API · 웹훅으로 예약 · 체크인 · 체크아웃 · 객실 번호를 받을 수 있는지, (2) 펫 동반 속성 · 직접 예약 재고를 쓸 수 있는지, (3) 소유주용 매출 · 점유율 리포트입니다.
- 설치형 PMS를 파우코리아 서버실에 두는 안은 **기본이 아닙니다**. 브랜드가 온프레미스 설치를 요구할 때만 랙 7~12번 예비를 씁니다.
