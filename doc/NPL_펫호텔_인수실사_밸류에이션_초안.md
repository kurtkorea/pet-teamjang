# NPL 펫호텔 인수 — 실사 · 밸류에이션 (초안)

> 대상: 오픈 직전 NPL로 멈춘 프리미엄 펫호텔(붉은 벽돌 3층 + 인접 제2동으로 추정) · 현장 사진 기준
> 목적: "인수해도 되는가 / 얼마에 / 무엇을 해결해야 여는가"를 한 장으로 판단
> 전제: 금액·연면적·객실수·위치는 **가정치(TBD)** — 실측·실사로 갱신. 저희는 이미 **동물위탁관리업 등록** 경험 보유.

---

## 0. 한눈에 — 인수 논리

- **매력**: 가장 무거운 **인테리어·설비 capex를 선투자자가 태운** 턴키 플래그십. 유리문 객실 + **돔 카메라(사진상 설치 추정)** = PET-Aeye 얹기 최적. NPL 특성상 **감정가 대비 큰 할인** 여지.
- **핵심 질문**: *"오픈 직전에 왜 멈췄나."* 자금(건설·운영자금 소진)이면 저희에게 기회, **입지·수요** 문제면 저희도 같은 벽. → 폐업 원인 규명이 1순위.
- **치명 리스크 Top3**: ① **유치권**(공사 중단·자재·비계 = 시공사 점유 주장) ② **건축물 용도/위반·사용승인** ③ **동물시설 인허가·오폐수·민원**.

## 1. 인수 구조 (어떤 경로로 사는가)

| 경로 | 내용 | 장점 | 유의 |
|------|------|------|------|
| NPL 채권 매입 → 경매 | 부실채권(근저당부채권)을 할인 매입 후 경매 주도 | 저가 확보·방어입찰 | 채권평가·배당분석 역량 필요 |
| 경매 직접 응찰 | 경매 물건에 직접 입찰 | 단순 | 경쟁·고가낙찰 위험 |
| 공매(자산관리공사 등) | 공매 플랫폼 매각 | 투명 | 조건·일정 경직 |
| 임의매각(수의계약) | 채권자·소유자와 직접 협상 | 속도·현상유지 인수(설비 포함) | 권리관계 정리 선행 |

> **설비·장비 포함 여부**가 가치의 큰 부분(스파 욕조·드라이어·미용기·CCTV·가구). 매각 범위(부동산만 vs 집기 포함)를 반드시 명문화.

## 2. 권리분석 체크리스트 (가장 위험 — 선(先)확인)

- [ ] **등기부등본**: 근저당 순위·채권최고액, 가압류·가처분·신탁 여부
- [ ] **선순위 임차인·대항력·확정일자**(배당 요구 여부), 상가임대차 해당 여부
- [ ] **유치권**: 현장 점유자 유무(사진의 비계·자재·잔해 = 시공사/인테리어 **유치권 주장 신호**) → 점유 사실·공사대금채권 확인, 성립요건 다툼 여지
- [ ] **체납**: 재산세·종부세, 4대보험, 전기·수도·가스, **관리비**(상당액일 수 있음)
- [ ] **리스·할부 설비**: 스파·공조·CCTV·주방기기 등 소유권유보·리스 잔존 여부
- [ ] 경매 시 **배당표 시뮬레이션** → 실제 필요자금·방어입찰가 산정

## 3. 건축 · 물건 체크리스트

- [ ] **건축물대장 용도**가 동물 관련 시설로 적법한가(제2종 근생/동물병원 등), **위반건축물** 등재 여부
- [ ] **사용승인(준공)** 완료 여부 — 미준공이면 개업 불가·추가공사
- [ ] **오폐수·정화조 용량**(동물 분뇨·목욕 배수 대응), 그리스트랩·바닥배수
- [ ] **소방**: 완비(완공필증), 스프링클러·제연·피난(사진에 피난구 유도등 확인)
- [ ] 승강기(화물/인승) 검사, 전기 수전용량(공조·드라이어·스파 동시부하), 공조·환기(악취·분진)
- [ ] **제2동**: 인수 범위 포함 여부·용도·연결 동선

## 4.1 입지 분석 — 인천 영종구 운남동 (확정)

**위치**: 인천 영종구 운남동로 44 · 영종하늘도시 생활권. **기존 마스터 기획서의 "인천공항 인접 + 신도시 반려가구" 테제와 동일 생활권** → 그린필드 가정이 실물 자산으로 치환됩니다.

| 항목 | 내용 | 시사점 |
|------|------|--------|
| 배후 인구 | 운남동 약 2.9만 명 / 1.36만 가구, 45개월 **+39% 급성장**(중위 41세) | 젊은 신도시 → 데이케어·호텔 실수요 |
| 반려 성향 | 단지 후기 "강아지 키우는 가구 많음", 산책로·공원 풍부·조용 | 생활권 수요 두터움 |
| 공항 접근 | **T1 차로 10분, 운서역 5분** | 공항 위탁(샌딩/픽업)·여행·출장 수요 |
| 상권 특성 | **도보 상권 약 · 차량 의존** | 현장 **대형 주차장**과 맞물려 **픽업·발렛 모델에 유리** |
| 경쟁 | 생활시설 多(음식점152·카페28·미용실27)이나 **반려 전문시설 희소** | 프리미엄 선점 여지 |
| 성장 | 신규 아파트 입주 지속, 제2동 여지 | 수요·확장 헤드룸 |

**리스크**: 도보 자연유입 적음 → 목적성 방문·픽업 영업 필요 / 신도시 신규 경쟁 진입 가능 / 공항 수요의 계절·여행 변동.

**폐업 원인 가설(입지 관점)**: 입지 수요 자체는 존재(공항 10분 + 신도시 반려가구). 따라서 고사양 3층 + 제2동 **과투자 대비 초기 가동률 미달·운영/자금 소진**으로 멈춘 **전형적 "자산은 양호, 자본구조가 터진" NPL**일 가능성. → *실사로 반드시 검증*(입지 문제였다면 저희도 동일 리스크).

| 항목 | 내용 | 비고 |

| 미시공 마감 | 철거/공사 중단 구역(일부 층·입구) 마감 | 사진상 수개 구역 |
| 설비 점검·복구 | 공조·전기·급배수·CCTV·NVR 가동 점검 | 방치 기간만큼 리스크 |
| 장비 상태 | 스파 욕조·드라이어·미용기·주방기기 작동/위생 | 중고 가치·수리비 |

| 초기 운영자금 | 인력·마케팅·소모품·안정화(가동률 램프업) | 3~6개월 |

## 6. 밸류에이션 — 총 인수원가 & 회수

**총 인수원가 = NPL 매입가(또는 낙찰가) + 권리해소비(유치권·체납·리스) + 잔여 capex + 초기 운영자금**

신축 대비 비교(TCO):

| 구분 | 신축/임차(영종 가정) | NPL 인수(본 건) |
|------|----------------------|------------------|
| 인테리어·설비 capex | 전액 신규 투자 | **선투자분 승계(핵심 절감)** |
| 시간 | 설계·시공 리드타임 | **마감·점검 후 조기 개업** |
| 불확실성 | 설계대로 | 실물 확인 가능(+권리 리스크) |

**회수(연 매출) 모델 — 가동률 3안**

```
연 매출 ≈ 객실수 × 365 × 가동률 × 평균 객단가
         + 부가매출(미용·스파·카페·PET-Aeye 안심옵션·졸업 리포트)
```

| 시나리오 | 가동률 | 비고 |
|----------|--------|------|
| 보수 | 35% | 램프업·브랜드 재구축 초기 |
| 기준 | 50% | 안정화 후 |
| 공격 | 65% | 프리미엄·부가매출 성숙 |

**손익분기 가동률** = 연 고정비 ÷ (객실수 × 365 × 객단가 × 공헌이익률). → 객실수·객단가·고정비 확정 시 즉시 계산 가능(값 주시면 모델 채워 드립니다).

## 7. 의사결정 게이트 (Deal-breaker)

- **BreaK**: 건축물 용도 부적합·위반 해소 불가 / 미준공 + 과다 추가공사 / 유치권·체납이 매입가를 잠식 / 입지상 동물위탁업 등록 불가
- **GO 조건**: 총 인수원가 < (기준 가동률 회수 기준 목표 멀티플) **그리고** 폐업 원인이 **자금(운영)** 이슈로 규명 **그리고** 권리 리스크 정량화·반영

## 8. 90일 인수 실행 타임라인(안)

1. **D0–15 사전실사**: 등기부·건축물대장·현장 점유 확인, 폐업 원인 탐문, 매각 경로 파악
2. **D15–40 정밀실사**: 권리분석·배당 시뮬, 설비·건축·인허가 전문가 동행 점검, 잔여 capex 견적
3. **D40–60 밸류에이션·입찰전략**: 총 인수원가·회수모델 확정, 방어입찰가/협상가 결정
4. **D60–80 인수 실행**: 채권매입/입찰/계약, 권리해소(유치권·체납)
5. **D80–120 개업 준비**: 마감·설비복구, **PET-Aeye 리트로핏**, 브랜드 전환, 인허가(위탁업 등록), 시범운영
