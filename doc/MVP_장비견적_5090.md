## 5. 이 프로젝트에서의 쓰임

| 워크로드 | 5090 필요성 | 비고 |
|----------|-------------|------|
| 추모 슬라이드·영상 생성 (ComfyUI 등) | **높음** | 32GB VRAM 유리 |
| 로컬 LLM (상담 초안·내부 자동화) | **높음** | 70B급은 양자화 전제 |
| 웹/OS 개발·배포 | 낮음 | 클라우드로도 가능 |
| 케이스 접수·정산 | 불필요 | 일반 PC |

**클라우드 대안:** GPU를 렌트(RunPod·국내 GPU 클라우드)하면 초기 CAPEX는 줄지만, 추모 원본·개인정보 로컬 처리·반복 생성 비용이 커지면 5090 소유가 유리할 수 있음.

## 6. 구매 시 체크

1. **전원:** 건물 콘센트·회로 여유 (5090 피크 대비). 멀티탭 저가품 금지.  
2. **재고:** 5090은 품귀·프리미엄 큼 → 조립샵 예약·세금계산서 가능처 우선.  
3. **RAM:** 128GB는 64×2가 32×4보다 클럭 유지에 유리한 경우가 많음.  
4. **보증:** GPU·PSU AS 기간 확인 (고전력 파트).  
5. **MVP 절감 옵션:** RAM 64GB로 시작(−100~150만) 후 증설 / 모니터 기존 전용.
