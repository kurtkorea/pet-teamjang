## 0. 封面摘要

PAWKOREA 就用于宠物**酒店、度假村与家庭**的  
**内置 NPU 的 IP 摄像机（主 SKU：集成 60 GHz FMCW 生命体征）**  
提出 ODM 开发与量产询价，要求 **单一 SKU** 覆盖三渠道。

| 项目 | 要求 |
|------|------|
| 产品 | 天花/壁挂固定摄像机 · **端侧 NPU 推理** |
| 连接 | **Wi-Fi + 以太网 + PoE(802.3af) 同一 SKU** |
| SKU | **仅生命体征版**（NPU + 60 GHz FMCW）· 一、二期合计约 **1,000 台** |
| 固件 | 买方 AI 模型 · **必须支持 OTA** · 默认仅上传结果/事件（非持续原始视频） |
| 渠道 | 永宗宠物酒店 · 横城宠物度假村 · 家用摄像头（同一主板） |

我方正在 MaixCAM2 / Axera **AX630C** 级开发板上做 PoC。  
欢迎提出 **同等或更优 SoC**；若替换，请说明性能、工具链、单价与芯片原产地。

## 4. 固件 · AI · 对接

### 4.1 职责划分

| 领域 | 买方（PAWKOREA） | ODM |
|------|------------------|-----|
| AI 模型 | YOLO 类 · NPU `.axmodel`（或约定格式） | 运行时集成 / 调优支持 |
| 应用 | 事件、监控、App、服务器 | 设备 Agent/SDK · 流媒体 · OTA |
| OTA 服务器 | **由买方建设与运营** | **交付设备侧 OTA Agent** |
| 云 | 买方 | 仅设备 · **禁止强制绑定 ODM 云** |

### 4.2 必备功能（P0）

| 功能 | 要求 |
|------|------|
| 推理 | 端侧 NPU · 检测/姿态 · **单帧多目标** |
| 输出 | 坐标/ID/事件至 **买方 API** · 禁止默认持续上传原始视频（可配置） |
| 视频 | **RTSP**（建议 H.265）· 主/子码流 · 支持 ONVIF 加分 |
| 智能录像 | 有事件高码率 · 空闲低码率 |
| 缓冲 | microSD 或 eMMC 断网缓冲 |
| 安全 | 每机证书（或同等）· 无默认密码 · **量产网禁止常开 SSH** |
| 配网 | 序列号/QR · Wi-Fi（家用）· 买方注册 API |

### 4.3 OTA（必须）

请分别报 **含 OTA** / **不含 OTA** 单价。

| 项目 | 要求 |
|------|------|
| 模型 OTA | 仅更换 AI 模型，无需整机刷 OS |
| 固件 OTA | OS / 应用 / Agent |
| 协议 | HTTPS · `/ota/check` · `/ota/report`（或约定） |
| 签名 | 买方（或指定）密钥 · **仅安装已签名包** |
| 回滚 | 安装/启动失败自动回退 |
| 上报 | 成功/失败 · 版本 · device_id |
| 验收 | DVT 完成 **金丝雀发布 + 回滚演示** 后方可量产 |

PoC 的 USB/SSH 刷机与 **量产 OTA 须分里程碑**。

### 4.4 生命体征版（主 SKU · 全部）— 60 GHz FMCW

**一期 500 + 二期 500 = 1,000 台全部为生命体征版。**  
结构、主板、固件、KC（含雷达频段）及下述 API 均须纳入报价。

生命体征为 **健康参考值（非医疗）**。固件与文档禁止诊断/疾病/医疗器械表述。

#### 硬件

| 项目 | 要求 |
|------|------|
| 传感器 | **60 GHz 级 FMCW 毫米波**（现货模组或指定 BOM） |
| 连接 | 与 SoC **UART 或 SPI** · 由摄像机板供电 |
| 结构 | 射频窗口 · 尽量减少对 IR/视场干扰 · 天花/高位壁挂 |
| 功能 | **在场/离场** · **呼吸节奏/每分钟呼吸（参考）** · 微动 ·（心率可选并写明精度限制） |
| 对象 | 近距室内 · 优先单目标（多目标非必须） |

#### API（摄像机固件作为网关）

App **不得**直接访问雷达芯片。路径仅为 **固件 → 买方服务器**。

- 协议：MQTT 和/或 HTTPS POST  
- 载荷：JSON（字段名启动会时确定）

```json
{
  "device_id": "string",
  "ts": "ISO-8601",
  "radar": {
    "presence": true,
    "breath_rpm": 18.5,
    "breath_confidence": 0.0,
    "motion_level": 0.0,
    "heart_bpm": null
  },
  "vision": {
    "pets": 0,
    "persons": 0
  }
}
```

| 要求 | 说明 |
|------|------|
| 周期 | 可配置（如 1–5 秒）· 空闲可降频 |
| 事件 | 在场变化 · 呼吸异常趋势 · 长时间无微动等 |
| 原始数据 | **禁止** 雷达 ADC 大数据常开上传 |
| 文档 | DVT 前提供 UART 映射 · JSON schema · 错误码 · 样例日志 |

#### 隐私（建议 · P1 / 加分）

- 对 `person` ROI **实时模糊** 后再推流/录像  
- 模糊前帧不存储、不传输（可配置）  
- 说明物理遮挡关闭时雷达是否可单独运行
