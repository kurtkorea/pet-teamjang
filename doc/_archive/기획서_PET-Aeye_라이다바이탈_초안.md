## 0. 한 줄 요약

PET-Aeye가 지금 제공하는 **'보이는 안심'(영상 + AI 행동)** 위에, WaveDyne FMCW 라이다 반도체를 CCTV에 결합해 **'느껴지는 안심'(비접촉 바이탈)** 을 더합니다. 보호자 리포트에 호흡·활동·수면 같은 개체 상태를 함께 담고, 이 센서를 펫호텔·병원·시니어 케어로 넓히는 것이 목표입니다.

## 1. WaveDyne 기술 — 무엇을 할 수 있는가 (IR 요약)

| 항목 | 내용 (출처: WaveDyne IR) |
|------|--------------------------|
| 방식 | WD-FMCW — 세계 유일 수준의 4세대 FMCW 라이다. 연속 주파수 변조로 **거리·속도·재질 동시 센싱** |
| 정보 차원 | **6D** (위치 X·Y·Z + 반사도 + 순간 속도 + 재질 판별 + AI 처리) |
| 정밀도 | 마이크론(μm)급 정확도, 1,000만 포인트급, 500m 탐지 (제품 목표치) |
| 형태 | 광반도체 + 신호처리 SoC + 솔리드스테이트 스캐너(KTN+메타렌즈) — **기계 구동부 0** |
| 가격 | 양산 목표 판가 50만원 / 300$ (AEVA 대비 약 1/52) |
| 강점 | **빛이 없어도 동작**(야간), **영상이 아닌 거리·속도 데이터**(개인정보 유출 없음), 안개·분진에 강인 |
| 일정 | 핵심 반도체 3종 FAB-in 2026.12 → First Silicon 2027.03 → FMCW 라이다 실증 |
| 융합 | 카메라 모듈사와 결합을 명시적으로 추진(LG이노텍·삼성전기 등). **카메라 + 라이다 융합**이 전략의 핵심 |

**PET-Aeye 관점의 함의 3가지**
1. **비접촉으로 미세 움직임을 잡는다.** μm급 거리 + 순간 속도(도플러) 측정은 흉곽의 미세 변위, 즉 **호흡·미동**을 접촉 없이 포착하는 기반이 됩니다.
2. **빛과 영상에 의존하지 않는다.** 야간·소등 상태에서도 동작하고, 출력이 영상이 아니라 거리·속도 데이터라 **프라이버시 민원에서 자유롭습니다.** 펫호텔 보호자 안심 상품과 성격이 정확히 맞습니다.
3. **카메라에 붙이는 방향으로 간다.** WaveDyne이 카메라 모듈사와의 융합을 전략으로 잡고 있어, **CCTV + 라이다 폼팩터**는 그들의 로드맵과도 일치합니다.

## 2. 꿀벌(스마트 벌통) 사례 확인 — 생체 적용의 레퍼런스

사용자 요청대로 IR의 꿀벌 관련 구현을 확인했습니다.

- **슬라이드 15 (TRACTION):** 캐시카우 'AI 솔루션' 중 **스마트 벌통 AI · 매출 0.7억 (예상 · 26.11 납품)**.
- **슬라이드 27 (APPENDIX · 캐시카우):** "초저전력 Edge AI 기반 노동력 절감형 스마트 벌통 — **벌통 내부 환경감지 센서의 데이터를 분석하여 꿀벌 성장에 최적 환경 제공.**"
- **슬라이드 25 (INVESTMENT):** "**스마트 벌통 AI 솔루션에 자체 칩 적용 예정.**"

**이 사례가 증명하는 것 (PET-Aeye에 중요한 이유)**
- WaveDyne은 이미 **살아 있는 생물(꿀벌)의 상태·환경을 센서 데이터로 읽어, 엣지 AI로 최적 환경을 만드는 제품**을 매출 단계까지 끌고 왔습니다.
- 즉 "센서 → 생체 상태 해석 → 환경 제어/알림"이라는 파이프라인을 **자체 칩으로 상용화한 경험**이 있습니다.
- 꿀벌이 **벌통 환경 최적화**라면, 반려견은 **객실 환경 최적화 + 개체 바이탈 모니터링**으로 같은 구조를 옮겨올 수 있습니다. 대상만 꿀벌 → 반려견으로 바뀝니다.

> 참고: WaveDyne의 1호 협업 파트너가 대동(자율·정밀농업)인 점도 '생체·환경 센싱' 적용 경험을 뒷받침합니다.

## 3. 비접촉 바이탈 체크 — 무엇을, 어떻게

### 3.1 측정 항목과 신뢰도 구분

| 항목 | 설명 | 기대 신뢰도 |
|------|------|-------------|
| 호흡수 · 호흡 패턴 | 흉곽 미세 변위(μm) 측정 | 높음 (핵심 지표) |
| 미동 · 활동량 | 순간 속도(도플러)로 움직임 세기·빈도 | 높음 |
| 수면/휴식 깊이 | 호흡·미동의 규칙성으로 추정 | 중간 |
| 재실 · 자세 · 낙상 | 3D 포인트로 위치·높이 변화 | 높음 |
| 체형 · 대략 체중 | 3D 스캔으로 부피 추정 | 중간 (보정 필요) |
| 심박 추정 | 미세 진동 성분 분리 | 낮음~중간 (연구·검증 단계) |

**원칙:** 호흡·활동·재실·낙상은 1차 상품에, 수면 깊이·체형은 2차에, 심박은 검증 후 조건부로. **의료 진단이 아니라 '웰니스·안심' 지표**로 포지셔닝합니다.

### 3.2 작동 방식과 프라이버시

- 룸 천장/벽의 **CCTV + FMCW 라이다 융합 센서** 한 대가 영상(관제·하이라이트)과 거리·속도(바이탈)를 동시에 확보합니다.
- 바이탈 산출은 **거리·속도 데이터 기반**이라, 영상 없이도 호흡·움직임을 읽습니다. 소등된 야간에도 끊기지 않습니다.
- 보호자에게 민감한 **영상 노출 없이도** 상태 리포트를 제공할 수 있어, 프라이버시 우려가 큰 보호자층까지 포용합니다.

## 4. 폼팩터 — CCTV + 라이다 융합 센서

```
[ PET-Aeye 룸 센서 (융합 폼팩터) ]
   ├─ 카메라 모듈      → 영상 · AI 행동 검출 (현재 PET-Aeye)
   ├─ WaveDyne 라이다  → 거리 · 속도 · 3D (호흡 · 미동 · 재실 · 낙상)
   └─ 엣지 AI          → 센서 퓨전 → 상태 요약 → 이벤트/리포트
                         (WaveDyne 멀티모달 AI SoC · LiDAR+Camera Fusion)
```

- WaveDyne IR의 **"LiDAR + Camera Fusion · 센서 퓨전 미들웨어"** 구조를 그대로 활용합니다.
- 1실 1센서를 기본으로, 우선 적용은 **3F 중대형·패밀리 26실**과 **격리실·노령견 객실**부터. (환자·고령 개체 우선)
- 기존 PET-Aeye 네트워크(관제실·녹화·관리자 웹)에 바이탈 채널만 추가하는 구조라, 관제·리포트 UI는 재사용합니다.

## 5. 보호자 CareReport에 바이탈 추가

현재 리포트(급식·산책·수면·스태프 메모)에 **개체 바이탈 섹션**을 더합니다.

| 리포트 블록 | 기존 | 추가 (라이다) |
|-------------|------|----------------|
| 활동 | 산책 횟수·거리 | 활동량 그래프(시간대별 미동) |
| 휴식 | 낮잠·야간 숙면(정성) | 호흡수 추이 · 수면 안정도(정량) |
| 안심 | 이상 행동 알림 | 호흡 급변·장시간 무호흡 미동·낙상 **조기 알림** |
| 요약 | 스태프 메모 | "오늘 호흡·휴식 안정" 등 상태 한 줄 요약 |

알림은 **고신뢰 규칙부터** 켜고(예: 재실 중 장시간 미동 + 호흡 패턴 이상 동시 충족), 스태프 확인 후 보호자에게 공유하는 현재 원칙을 유지합니다.

## 6. 호텔 확장성 — 이 기술로 더 할 수 있는 것 (분석)

사용자 요청에 따라, 바이탈 센서가 펫호텔에 만드는 추가 확장성을 정리했습니다.

| # | 확장 방향 | 내용 | 가치 |
|---|-----------|------|------|
| 1 | **시니어·메디컬 케어 객실** | 노령견·만성질환견 전용 층/객실에 바이탈 상시 모니터링 | 프리미엄 단가 · 차별화 |
| 2 | **야간·사각 보완** | 소등 후에도 호흡·재실 확인, 카메라 사각(침대 밑 등) 보완 | 24시간 안심 완성 |
| 3 | **낙상·발작·이상 조기경보** | 자세 급변 + 미동 이상으로 응급 상황 조기 포착 | 사고 예방 · 책임 리스크↓ |
| 4 | **객실 환경 최적화(벌통 응용)** | 온습도·소음·조도와 개체 바이탈 상관을 학습해 공조 자동 제어 | 꿀벌 모델의 직접 이식 |
| 5 | **입·퇴실 3D 체형 기록** | 입실/퇴실 시 체형·대략 체중을 비접촉 기록 | 건강 변화 추적 · 분쟁 예방 |
| 6 | **분리불안 정량화** | 활동·호흡 변동성으로 스트레스 지표화 | 훈련·케어 상품 근거 |
| 7 | **나동 동물병원 입원실 연계** | 입원견 비접촉 모니터링으로 면회 대체 | 2차 개발과 결합 |

### SaaS · 데이터 확장

- **바이탈 프리미엄 티어:** PET-Aeye SaaS에 'Vital' 상위 플랜 추가(기존 Basic/Plus/Pro 위). 하드웨어(융합 센서) + 바이탈 리포트 번들.
- **데이터 자산화:** 품종·연령·체격별 **정상 바이탈 베이스라인**을 축적 → 이상 탐지 정확도↑, 중장기 **펫보험·동물병원·헬스케어 제휴**의 근거 데이터로 활용.
- **하드웨어 공급 구조:** WaveDyne 양산 판가(목표 50만원/대)를 전제로, 센서는 PET-Aeye 폼팩터로 묶어 시설에 공급. WaveDyne은 부품·IP, PET-Aeye는 응용·운영.

## 7. 로드맵 · 검증 (WaveDyne 일정과 연계)

| 단계 | PET-Aeye | WaveDyne 전제 |
|------|----------|----------------|
| P0 · PoC 설계 | 측정 항목·리포트 정의, 1실 실증 설계 | First Silicon 2027.03 전후 |
| P1 · 단일 객실 실증 | 호흡·활동·재실 정확도 검증(반려견 대상) | FMCW 라이다 실증 단계 |
| P2 · 융합 폼팩터 | CCTV+라이다 센서 제작, 3F·격리실 적용 | 반도체 3종 양산 셋업 |
| P3 · 상품화 | 바이탈 CareReport 정식, SaaS Vital 티어 | 양산 판가 확보 |

**유의 사항 (정직하게)**
- WaveDyne 반도체는 **FAB-in 2026.12, 실증 2027** 로드맵상 제품이므로, 바이탈 기능은 **지금 운영 기능이 아니라 PoC·로드맵**입니다. 문서에서도 그렇게 표기합니다.
- 반려견은 **털·체격·품종 편차**가 커 사람 대상 사례보다 검증이 더 필요합니다. 심박은 특히 검증 후 조건부 도입.
- **의료기기가 아니라 웰니스·안심 지표**로 포지셔닝해 규제 리스크를 피합니다. (이상 소견은 '수의 상담 권유'로 연결)
