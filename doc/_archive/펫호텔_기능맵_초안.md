## 3. peti 현재 구현 상태 (AS-IS)

코드베이스: `peti-mvp` (Rust ingest · Python AI worker · Node API · React admin)

| 영역 | 상태 | 비고 |
|------|------|------|

| YOLO 사람/개 검출 · ByteTrack | 동작 | `apps/ai-worker` |
| 행동 라벨(이동·자세 휴리스틱) | 초보 | standing/walking/running/sitting/lying/resting |

| Redis → WebSocket 실시간 | 동작 | `/ws/detections` |
| 라이브 MJPEG 스트림 · PTZ · auto-track | 동작 | admin 모니터 |
| Room / Stay / Guardian / Pet 마스터 | **미구현** | 비즈 연동 필수 |
| 보호자용 열람·리포트 | **미구현** | P1 |
| 멀티 카메라·룸 그리드 | **미구현** | P0 |

## 4. 도메인 모델 (TO-BE)

```
Guardian ──┬── Stay ──── Room ──── Camera(s)
           │      │
           └── Pet ┘
                  │
                  └── PetEvent ──► CareReport
```

| 엔티티 | 설명 | peti 테이블/필드 (초안) |
|--------|------|-------------------------|
| Guardian | 보호자 | `guardians` (name, phone, …) |
| Pet | 반려동물 · 장기적으로 배웅과 **Pet ID** 공유 | `pets` |
| Stay | 체크인~체크아웃 위탁 구간 | `stays` (pet_id, room_id, starts_at, ends_at, status) |
| Room | 객실 타입/호실 (소·중·대·패밀리) | `rooms` |
| Camera | RTSP/ONVIF 장치 | `cameras` (room_id, rtsp_url, …) |
| PetEvent | 검출·행동·알람 | 기존 `pet_events` + **stay_id, room_id, pet_id** |
| CareReport | 일일/퇴실 요약 | `care_reports` (stay_id, date, summary_json, sent_at) |
| AccessToken | 보호자 Stay 기간 한정 열람 | `stay_access_tokens` (expires_at) |

**트랙↔Pet 매핑:** P0~P1은 입실 시 스태프가 track/구역을 Pet에 **수동 지정**. 자동 재식별은 P2+.

## 5. 기능 맵 — peti 구현분

### 5.1 P0 — 현장 관제 (스태프)

| 기능 ID | 기능 | 정의 | AS-IS |
|---------|------|------|-------|
| H-CAM-01 | 카메라 등록 | RTSP/ONVIF, 이름, 활성 | 환경변수 단일 캠 |
| H-CAM-02 | 룸 매핑 | Camera N ↔ Room 1 | 미구현 |
| H-MON-01 | 룸 모니터 그리드 | 객실별 라이브/최근 프레임 | 단일 뷰만 |
| H-MON-02 | 검출 오버레이 | dog/human bbox · behavior | 구현됨 |
| H-EVT-01 | 이벤트 타임라인 | stay/room/camera 필터 | 목록 API만 |
| H-EVT-02 | 스태프 알람(기본) | 장시간 무움직임, 비인가 사람 등 규칙 | 미구현(휴리스틱 확장) |
| H-PTZ-01 | PTZ·자동추적 | 공용/복도 캠 | 구현됨 |
| H-REC-01 | 세그먼트 녹화·보관 | 일자 경로 저장, 보존 일수 | 녹화 골격 |

**P0 완료 정의:** 영종 2F/3F 가정으로 카메라≥2대, 룸 그리드에서 이벤트 확인 가능.

|---------|------|------|------|

## 6. 이벤트 → 운영 액션 (규칙 초안)

| 신호 (peti) | 스태프 액션 | 보호자 노출 |
|-------------|-------------|-------------|
| 장시간 무움직임 / lying 지속 | 현장 확인 · 필요 시 병원 | 옵트인 알림 또는 리포트 |
| 과도한 running 반복 | 산책·성향 케어 · 격리 검토 | 일일 리포트 |
| 비인가 구역 human 검출 | 보안·이중문 점검 | 원칙적 비노출 |
| Stay 종료 | 토큰 폐기 · 아카이브 | 하이라이트 제공(선택) |

행동 라벨은 현재 휴리스틱 단계이므로, **알람은 고정확 규칙만 P0에 넣고** 나머지는 스태프 검증 후 공유(호텔독스형 “베타 검증” 톤).
