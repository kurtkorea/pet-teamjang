## 0. 커버 레터 (요약)

파우코리아는 반려동물 **호텔·리조트·가정**에 동일 SKU로 공급할  
**NPU 내장 IP 카메라(주력: 60GHz FMCW 바이탈 일체형)** 의 ODM 개발·양산 견적을 요청합니다.

| 핵심 | 내용 |
|------|------|
| 제품 | 천장·벽 설치형 고정 카메라 · **기기 내 NPU 추론** |
| 연결 | **Wi-Fi + 이더넷 + PoE(802.3af) 단일 제품** |
| SKU | **바이탈형 단일** (NPU + 60GHz FMCW) · 1·2차 합 **약 1,000대** |
| 펌웨어 | 발주처 AI 모델 · **OTA 필수** · 결과·이벤트만 서버 전송 |
| 채널 | 영종 펫호텔 · 횡성 펫리조트 · 가정용 홈캠 (동일 기판) |

개발보드(MaixCAM2 / Axera **AX630C** 계열)로 PoC 중입니다.  
**동일 또는 동등 이상 칩** 제안을 환영하며, 대체 시 성능·도구·단가·원산지를 명시해 주십시오.

## 1. 사업 배경 (발주처 맥락)

| 채널 | 역할 | 카메라 연결 (현장) |
|------|------|-------------------|
| **영종 펫호텔** (운남 · 약 112실) | 위탁 객실·공용 안심 관제 (PET-Aeye) | 주로 **Wi-Fi** · 기존 전원 재사용 · 일부 PoE |
| **횡성 펫리조트** | 객실·실내 공용 (신축) | 주로 **PoE** |
| **홈캠** | 가정 구독 · 호텔 기록 연계 | **Wi-Fi + DC 어댑터** |

한 번의 모델·펌웨어 OTA로 **세 채널에 동일 배포**하는 것이 목표입니다.  
이벤트 규칙·알림 톤만 채널별로 다르게 둡니다.

**ODM이 하지 않는 것 (범위 외)**

- 관제 서버 · GPU 서버 · NAS · NVR  
- BLE 태그(Minew 등) · BLE 게이트웨이(MOKO 등)  
- 개발용 노트북/워크스테이션  
- 보호자 앱·클라우드 전체 (기기는 발주처 API로만 연동)

### 4.4 바이탈형 (주력 · 전량) — 60GHz FMCW

**1차 500 + 2차 500 = 1,000대 전량 바이탈.**  
기구·보드·펌웨어·KC(레이더 대역)·하기 API를 **필수**로 견적해 주십시오.

바이탈은 **웰니스 참고값(비의료)** 입니다. 진단·질병·의료기기 표현 금지.

#### 하드웨어

| 항목 | 요구 |
|------|------|
| 센서 | **60GHz급 FMCW mmWave** (시판 모듈 또는 지정 BOM) |
| 연결 | SoC와 **UART 또는 SPI** · 카메라 보드 전원 |
| 기구 | RF 창 · IR·화각 간섭 최소화 · 천장·벽 상부 |
| 기능 | **재실/부재** · **호흡 리듬·분당 호흡수(참고)** · 미동 · (심박은 옵션·한계 명시) |
| 대상 | 근거리 실내 · 1체 우선 (다중 분리 필수 아님) |

#### API (카메라 펌웨어가 게이트웨이)

앱이 레이더 칩을 직접 호출하지 않습니다. **펌웨어 → 발주처 서버만.**

- 프로토콜: MQTT 및/또는 HTTPS POST  
- 페이로드: JSON (필드명은 킥오프 시 확정)

```json
{
  "device_id": "string",
  "ts": "ISO-8601",
  "radar": {
    "presence": true,
    "breath_rpm": 18.5,
    "breath_confidence": 0.0,
    "motion_level": 0.0,
    "heart_bpm": null
  },
  "vision": {
    "pets": 0,
    "persons": 0
  }
}
```

| 요구 | 내용 |
|------|------|
| 주기 | 설정 가능(예: 1~5초) · 유휴 시 완화 |
| 이벤트 | 재실 변화 · 호흡 이상 추세 · 장시간 미동 등 |
| 원본 | 레이더 ADC 대용량 상시 업로드 **금지** |
| 문서 | UART 맵 · JSON 스키마 · 오류 코드 · 샘플 로그 (DVT 전) |

#### 프라이버시 (권장 · P1/가산점)

- `person` ROI **실시간 블러** 후 스트림·녹화  
- 블러 전 프레임 미저장·미전송(설정)  
- 물리 셔터 OFF 시 레이더만 동작 가능 여부 명시
