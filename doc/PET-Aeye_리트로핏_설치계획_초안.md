# PET-Aeye 리트로핏 설치계획 — 인수 펫호텔 (초안)

> 대상: 인수 예정 프리미엄 펫호텔(붉은 벽돌 3층 + 제2동 추정) · 현장 사진 기준
> 목표: **기존 하드웨어를 최대한 재사용**해 PET-Aeye(관제·행동검출·보호자 안심·CareReport·졸업 리포트)를 **최소 비용·최단 기간**으로 얹기
> 보안: RTSP 계정·`.env`(예: `peti-mvp`)는 노출 금지. 열람권한·감사로그 필수.

---

## 0. 현장 호재 (사진에서 읽히는 것)

- **전 객실 유리문** → 정면 1카메라로 개체·행동검출 커버리지 우수(사각 최소)
- **천장 돔 카메라 다수(설치 추정)** → 복도·라운지·놀이방·로비에 기존 인프라 존재 가능성
- **구역 다양**: 켄넬형 객실·프리미엄 스위트·복층 테마룸·미용실·펫 스파·옥상 놀이방·카페·로비 → PET-Aeye의 **룸/존 모델**에 그대로 매핑
- 리스크: 방치 기간 배선·전원·녹화장비(NVR) 상태, 카메라 **제조사·코덱·RTSP 지원** 여부(ONVIF/RTSP면 바로 수용)

---

## 1. 설계 원칙

1. **재사용 우선**: 기존 카메라가 **ONVIF/RTSP·H.264/265** 지원이면 그대로 수신. 미지원·고장만 교체.
2. **중앙 관제 신설**: 관제실(스태프) + **NVR/녹화 스토리지** + 서버(검출·이벤트·웹). 클라우드 기본, 회선 약하면 엣지 장비.
3. **네트워크 분리**: 카메라 VLAN ↔ 서비스망 분리, 보호자 노출은 **기간 한정 토큰**만.
4. **단계 적용**: 3F 프리미엄·격리·노령견 우선 → 전 층 확대(라이다 바이탈은 이후 PoC).

## 2. 구역별 카메라 계획

| 구역 | 목적 | 카메라 방침 | 보호자 노출 |
|------|------|-------------|-------------|
| 켄넬형 객실 | 개체·행동검출, 라이브 | 유리문 정면 1대(재사용/증설) | 배정 룸만(옵트인) |
| 프리미엄 스위트·복층 | 광각+상단 2대(복층 사각 보완) | 증설 가능 | 배정 룸만 |
| 복도 | 순찰·이상 동선 | 기존 돔 재사용 | 비노출 |
| 펫 스파·미용실 | 안전·분쟁 예방 기록 | 기존/증설 | 비노출(사고 시 내부 확인) |
| 옥상 놀이방 | 그룹 활동·사회성 | 광각 1~2대 | 하이라이트 클립 소재 |
| 로비·입구 | 보안·출입 | 기존 재사용 | 비노출 |

## 3. 소프트웨어 매핑 (PET-Aeye 도메인)

- **Room**: 물리 객실 ↔ PET-Aeye Room 등록(층·타입·번호), 사진의 켄넬/스위트/테마룸 체급 반영
- **Camera**: RTSP URL·좌표·존(Zone) 규칙(급식대·문앞 등)
- **Stay / Guardian / Pet**: 체크인 시 반려견 ↔ 카메라 트랙 연결, 기간 한정 링크 발송
- **PetEvent → CareReport → 졸업 리포트**: 투숙 중 이벤트 적재 → 일일 요약 → 퇴실 종합 리포트
- **열람 감사 로그**: 보호자·스태프 영상 열람 기록

## 4. 실행 단계

1. **실측·점검(D0–10)**: 카메라 수량·모델·RTSP 지원 조사, 배선·전원·NVR 생사 확인, 네트워크 도면화
2. **재사용/교체 판정(D10–20)**: ONVIF/RTSP 가능 목록 vs 교체 목록, 증설 지점 확정(복층·놀이방)
3. **인프라 구축(D20–40)**: 관제실·서버·스토리지, VLAN·방화벽, 녹화 보존정책(동물시설 기준·동의)
4. **PET-Aeye 온보딩(D40–55)**: 카메라 자동검색(ONVIF)·룸 매핑 마법사, 검출/트래킹 튜닝(YOLO+ByteTrack)
5. **시범운영(D55–70)**: 알림 규칙·오탐 조정(오픈 후 30일 데이터로 재튜닝), 보호자 링크·CareReport·졸업 리포트 가동

## 5. 비용 틀 (값 확정 전 항목만)

| 항목 | 비고 |
|------|------|
| 카메라 재사용/증설·교체 | 재사용률이 비용 좌우(현장 조사로 확정) |
| NVR·스토리지·서버 | 채널 수·보존기간 기준 |
| 네트워크(스위치·VLAN·회선) | PoE·대역폭 |
| 관제실 셋업 | 모니터월·PC |
| 설치·튜닝 인건 | 단계별 |
| (후속) 라이다 바이탈 PoC | PART 4 로드맵 — 지금 단계 아님 |

## 6. 리스크·주의

- 기존 카메라가 **독자 프로토콜/구형 코덱**이면 재사용률↓ → 비용 재산정
- 방치로 인한 **전원·배선·NVR 손상** 가능 → 초기 점검 필수
- 프라이버시: 보호자 노출은 **배정 룸·기간 한정**만, 미용·스파·복도는 내부 기록용
- 보안: RTSP 자격증명·`.env` 노출 금지, 접근권한 최소화·감사로그
