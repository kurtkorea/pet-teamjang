# MVP 장비 견적 — 파우코리아 펫호텔 영종 (BLE · 게이트웨이 · CCTV)

> 대상: **운남 · 파우코리아 펫호텔 영종** (본관 112실 · 약 370평)  
> 기준일: 2026-10 · 단위 **만원 · VAT 별도**  
> 근거: `PET-Aeye_CCTV_서버_비용산정_초안.md` v0.4 · `PET-Aeye_넓은공간_BLE개체추적_초안.md` v0.4 · 마스터 기획서  
> 상태: **참고 BOM** · 현장 실측·시공사 견적 3곳 이상으로 확정  
> 제외: ODM 금형·KC(홈캠과 공유) · 바이탈 레이더 PoC · 배웅(장례) 장비  
> 포함: **개발용 RTX 5090 노트북 1대** (현장 서버 GPU와 별도)

## 1. 한 줄 요약

| 티어 | 범위 | CAPEX 밴드 |
|------|------|------------|
| **A. MVP 파일럿** | 객실 30실 CCTV + BLE 1존 + 최소 서버 + **5090 개발 노트북** | **약 0.38~0.50억** |
| **B. 본관 전면 (권고 본선)** | NPU 150 + 실외 6 + BLE + 관제 최소 + **5090 개발 노트북** | **약 0.96~1.10억** |
| **C. 본관+별관** | B + 별관 확장 | **약 1.05~1.25억** |

**권고:** 오픈 전 검증은 **A**, 정식 가동은 **B**.  
개발용 5090 노트북은 **A부터 공통**으로 잡는다(모델 학습·펌웨어·앱 현장 디버그).

> 현장 **추론 서버용 5090은 NPU 기준안에서 불필요**.  
> 노트북은 **개발·실험·출장 디버그** 전용.

## 2. 시스템 역할 분담

| 레이어 | 하는 일 | 장비 |
|--------|---------|------|
| **CCTV / NPU 캠** | 객실·공용 **행동·이상 이벤트** · 보호자 라이브 · 30일 녹화 | NPU 통합형 캠 · 실외 IP캠 · AP/PoE · 녹화·앱 서버 |
| **BLE** | 플레이존·루프탑 **개체 ID · 구역 체류 · 이탈** | Minew MWB01 태그 · MOKO MKGW1-BW 게이트웨이 · 목줄 케이스 |

카메라는 “무슨 행동을”, BLE는 “어느 개가 어느 구역에”.

## 6. GPU(5090) 역할 정리

| 경로 | 장비 | 비고 |
|------|------|------|
| **개발 (본 BOM 포함)** | **5090 노트북 1대** | 모델·펌웨어·현장 디버그 · **약 700~800만** |
| NPU 현장 추론 | GPU 서버 **불필요** | 카메라 NPU + 실외 엣지 |
| 서버형(시중캠) | 데스크톱 GPU 서버 1~2대 | 별도 · +1.2~2.4천만 |
| 대형 학습 | 클라우드 GPU / 데스크톱 5090 | 노트북 VRAM·전력 한계 시 |

노트북 5090(모바일) ≠ 데스크톱 5090. 학습 규모가 커지면 데스크/클라우드를 추가한다.
